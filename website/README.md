# S-Arena Gaming Website

A modern, responsive gaming platform website for S-Arena - featuring Ludo, Chess, Carrom, and 8-Ball Pool.

## 🎮 Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern UI** - Dark theme with gradient accents and smooth animations
- **Multiple Sections**:
  - Hero section with call-to-action
  - Featured games showcase
  - Features/benefits highlighting
  - Active tournaments display
  - Statistics section
  - Contact form
  - Footer with links

- **Smooth Interactions** - Hover effects, smooth scrolling, and button animations
- **Performance Optimized** - Fast loading, minimal dependencies

## 📁 Files

- `index.html` - Main HTML structure
- `styles.css` - Comprehensive CSS styling with animations
- `script.js` - Interactive JavaScript functionality

## 🚀 Quick Start

1. Open `website/index.html` in your browser
2. Customize the content as needed
3. Deploy to GitHub Pages for hosting

## 🎨 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6b5aff;
    --secondary-color: #00d4ff;
    --accent-color: #ff006e;
    --dark-bg: #0a0e27;
    --darker-bg: #05070f;
}
```

### Content
Update game names, features, tournaments, and contact information directly in `index.html`
